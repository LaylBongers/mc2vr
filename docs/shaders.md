# Reimplemented shaders

The game's shaders rewritten as HLSL (`src/carrier/reimpl/shaders/`), compiled at build time with Microsoft's `d3dcompiler_43` ([build.md](build.md#hlsl-shader-compiler)) and substituted when the game creates the originals. Like the C++ reimplementations ([reimpl.md](reimpl.md)), they read like the originals and change what needs changing.

## Mechanism

- **Substitution:** the glue is in `hooks/shader_reimpl.cpp`, the shader counterpart of `hooks/reimpl.cpp`. It holds the replacement list, one line per shader, and the HLSL in `reimpl/shaders/` is the reimplementation itself. The device's `CreatePixelShader` (vtable slot 106, `hooks/device.cpp`) passes each creation's bytecode to `hooks::shader_reimpl::substitute_pixel_shader`.
  - It hashes the bytecode (FNV-1a over the token stream up to the end token, as `tools/shader_hash.py`).
  - For a reimplemented original it returns our bytecode instead.
  - The game keeps the object it gets back, so its caches stay consistent ([hooks.md](hooks.md)).
  - If the device refuses ours, the original is created and the entry is disabled (logged as an ERROR).
- **The interface stays the original's:** the same input semantics, the constant names at the same registers (explicit `register(cN)`), the same samplers. The game resolves and uploads constants by name, so it drives ours unchanged.
  - Check: `tools/shader_iface.py <game>/data/shader3.bin`. For every registry entry it compares the generated bytecode (`build/win32/generated/shaders/<name>.h`) with the original (`shader3.bin@offset`):
    - the input and sampler declarations;
    - every constant-table entry (name, register set, register, count);
    - the static `if bN` structure, with empty `else` arms dropped, since their placement is codegen;
    - the registry hash against the container.
    It doesn't check the math.
  - **Math:** `tools/shader_equiv.py <game>/data/shader3.bin` checks the math. It emulates each original and ours, as SM3 bytecode in numpy, on 1000 random trials, and compares the outputs to 1e-4.
    - **Inputs:** random inputs, constants and bools, so every light-count branch gets covered. The light constants are drawn in plausible ranges.
    - **Samplers:** each mocked as a smooth function of its UV. The sun shadow map is mocked as one constant depth per trial, so the 1-tap and 9-tap lookups agree and any difference is a porting error.
    - **Shadow UV side:** for originals that already take 9 shadow taps (the PgDiff families), the random-depth trials add noise per atlas texel, so the tap offsets, bilinear weights and cascade rows are compared too. A tap moved by half a texel in `shadow.hlsli` was caught (2026-11-15).
    - **Blind spots:** for the single-tap originals, the shadow-map UV side (cascade u/v rows, tap offsets, the 9-tap's bilinear weights), constants that never reach the output (the 30000 clamp), and real screen-space derivatives (`dsx`/`dsy` are mocked). Those need checking in game.
    - **Options:** `--self` compares each original with itself; `--perturb neg|def[:K]` corrupts ours, to show it gets caught.
    - **Tested (2026-11-13):** a deliberate reflection-weight × 0.9 and a shoreline factor of 0.95 → 0.96 in PgWaterFPDWE were both caught.
    - Run both tools after every shader change. Each takes well under a second. Since the cascade blend band ([shadows.md](shadows.md)), run them as `shader_iface.py --shadow-band` and `shader_equiv.py --shadow lit`. The band is a deliberate difference from every original.
- **Debug tools:** tools that hash the bound shader (`ps_census`, `camera_census`) see our bytecode's hash for replaced shaders, not the original's.
- **Always on:** the `shader_reimpl=on|off` A/B was removed (2026-11-14). Compare against an older build if a shader is ever in doubt.
- **Atlas size:** at a non-stock `shadow_resolution`, every 9-tap receiver's atlas texel `def` constants are rescaled at creation, ours and the game's 315 alike ([shadows.md](shadows.md)). `tools/shader_iface.py` and `shader_equiv.py` check the stock-size bytecode.
- **Log:**
  - `shaders: <hash> <name> -> reimplementation` at each substitution.
  - `shaders: window:` with the substitution counts per entry, logged only when shader creations happened.

- `global_light.hlsli`: `globalLightData`'s layout and the ambient cube: six colours `[3..8]` picked by the normal's signs, weighted by N².
- `shadow.hlsli`: the shared sun-shadow lookup, cascade selection and the 9-tap kernel, transcribed from the high-quality receiver `shader3.bin@0x11570`.
- `lights.hlsli`: the local lights.
  - **Point light** (3 registers: position, colour, attenuation): `saturate(dist·x + z) · colour · N·L`.
  - **Spot light** (4 registers): a distance falloff and a cone falloff, each a `pow` by the light's exponent, zero behind the light, times N·L.
- **`PgDiff.hlsl`**, the game's material shaders. The names combine features (Diff, Spec, Norm, AmbOcc, Refl, Metal, Emis, Rim, SSS), so one source takes a define per feature. A CMake family entry `<name>:<source>:<defines>` builds each family in its 7 light variants. The features ported so far:
  - **`MC2VR_PGDIFF_SPEC`:** `specularMap`, and Blinn-Phong from the sun and the local lights. The sun's highlight is scaled by `max(0.25, visibility)`. The specular luminance can raise the alpha.
  - **`MC2VR_PGDIFF_NORM`:** a tangent-space normal map (x in alpha, y in green; frame from `TEXCOORD1`–`3`). The originals rebuild z as `sqrt(1 − x² − 2y)`, a linear y term that looks like a slip in the game's source. It's kept, to stay identical.
  - **`MC2VR_PGDIFF_AMBOCC`:** `COLOR0` multiplies the lit colour and the alpha.
  - **`MC2VR_PGDIFF_METAL`:** a `reflectionMap` cube at `reflect(−V, N)`, tinted by the specular map, weighted by Fresnel⁵ · `materialData[5].x`.
  - **`MC2VR_PGDIFF_REFL`:** the same reflection without Fresnel, times `materialData[5].x`.
  - **`MC2VR_PGDIFF_EMIS`:** `emissiveMap` (s1) × `materialData[3].rgb`.
  - **`MC2VR_PGDIFF_RIM`:** `max(dot(−V, N) + globalLightData[2].w, 0)` · `globalLightData[2].rgb` · `(1 − N·L)` (N·L unclamped), inside the saturated direct light.
  - **`MC2VR_PGDIFF_SSS`:** the wrapped band `smoothstep(−w, 1, N·L) − smoothstep(0, 1, N·L)` (w = `materialData[4].w`) × `materialData[4].rgb`, unshadowed and sun-only. Combined with Rim, the rim also goes through the band, weighted by `(1 − sunBand)`.
  - **Placement:** the reflection and emissive terms are added before AmbOcc's `COLOR0` multiply, confirmed by the Metal+AmbOcc and Refl+AmbOcc families.
  - **Without Norm:** the normal is `normalize(TEXCOORD3)`, and the ambient is `COLOR1` × `materialData[2]`. **Without Spec:** diffuse-only local lights and an unsaturated alpha.
  - `#error` guards reject the combinations the game never builds.
  - `lights.hlsli` now also gives the local lights' Blinn-Phong specular (`local_lights_spec`). `local_lights` keeps the diffuse-only form the other families use.
- **Variants:** each family comes in 7, built from one source with defines (`src/carrier/CMakeLists.txt`). The generated symbols carry the originals' file names: `PgFastFP`, `PgFastFP_pl`, `_pl_li`, `_pl_sl`, `_pl_sl_li`, `_sl`, `_sl_li`. They are no local lights, or point and/or spot lights in one of two counting schemes:
  - **plain** (`_pl`, `_sl`, `_pl_sl`): the highest set bool picks the count. Points take 8/4/2/1 by `b3`/`b2`/`b1`/`b0`; spots take 4/2/1 by `b6`/`b5`/`b4`.
  - **`_li`** (`MC2VR_LIGHTS_LI=1`): 2 lights always, +2 if `b2` (points) or `b6` (spots), and points +2 more if `b3` is also set.
  - The two families differ only in their inputs. The distant one doesn't normalize the normal or saturate the direct light; the near one saturates sun plus local lights.

## Modern shading (optional)

A deliberate look change for the 280 PgDiff materials only, selected by conf `shading=classic|modern` (default `classic`). Every PgDiff variant is also built with `MC2VR_SHADING_MODERN=1` as `<symbol>_modern`, and `hooks/shader_reimpl.cpp` picks the set at creation; the atlas texel scaling applies to either. Classic is the faithful set, verified against the originals. Terrain, vegetation, decals and water have no modern set.

- **Direct light** (sun and every point/spot light, `lights.hlsli` `local_lights_pbr`):
  - **Specular:** GGX · Smith height-correlated visibility · Schlick Fresnel · N·L · π. The π is because the game's units have no 1/π.
  - **Diffuse:** Burley · (1 − F).
  - **Shadow:** fully applied to the sun's specular, so the classic 25% leak is gone.
- **Material** from the Blinn-Phong assets:
  - α = clamp(√(2 / (n + 2)), 0.03, 1), with n = `materialData[5].z`.
  - Tint = specular map × `materialData[1]`. Dielectric F0 = 0.04 + tint · `kSpecF0Scale` (0.25).
  - **Every surface is a dielectric with its full albedo.** The game's "Metal" is an environment-mapped reflective material (car paint, glass, panels), not bare metal. A first version derived metalness from the specular map's luminance, and coloured car paint washed out to grey with pink splotches (live, 2026-11-15). It was removed.
  - **Families without Spec:** F0 = 0.04, α = 0.6.
  - The normal map's z uses the correct √(1 − x² − y²), where classic keeps the original's slip.
- **Ambient and environment:**
  - **Diffuse ambient** (ambient cube or vertex ambient): × (1 − EnvBRDF) × AO.
  - **Specular ambient:** the ambient cube along R (Norm families) or the vertex ambient, weighted by Karis's `EnvBRDFApprox` × `kEnvStrength` (1.0) × AO.
  - **Metal/Refl reflections are the artists' own,** as in the originals: the reflection cube × the specular map × the original weight (Metal's Fresnel `lerp(materialData[2].w, 1, (1 − N·V)⁵) · materialData[5].x`, Refl's constant `materialData[5].x`), added over the full-colour base. The cube is read near-sharp: the mip is GGX α × 6, capped at 1 (`kReflectionMipMax`).
  - **Why:** a material census (`debug_material_census`, 2026-11-15; 673k reflective draws, 58 settings) found Fresnel bases of 0–0.29 only (44% at 0, 26% at 0.29), strength 0.2–0.8 and exponents 16–350. Every reflective material is authored as a Fresnel-weighted reflection over its colour, and no constant marks a metal, so there's no automatic metal path. A first coat version, with the base dimmed by 0.5 of the weight and the mip at √α × 6 (~mip 3 on glossy paint), made car reflections look weak (live, 2026-11-15).
  - **Optional, later:** hand-tag metal settings, e.g. with a debug key that highlights one material setting, and give those a metal path.
  - AO now darkens only ambient and environment, not direct light.
- **Unchanged:** rim, SSS and emissive work as in classic. The alpha is raised by the modern specular's luminance.
- **Compromises:**
  - PgDiffFP, AmbOcc, Emis and EmisAmbOcc (28 shaders) have no `cameraPos` in their interface, so no view direction. They take V = N: no direct specular; Burley and the energy split only.
  - Non-Norm families' environment has no direction.
  - Shading stays in the game's gamma space.
  - Light-heavy variants run about twice the instructions.
- **Checks:**
  - `shader_iface.py --modern`: inputs, samplers and constants within the original's interface, since the game sets nothing else.
  - `shader_equiv.py --modern-finite`: no NaN or infinity where the original is finite, on plausible lights. It also gives each family's modern/classic luminance ratio as a calibration aid: about 0.55–0.9 for Metal/Refl, 0.76–0.87 for Spec without AmbOcc, 0.9–1.2 elsewhere.
- **OPEN:** calibration in the HMD, plus a cost check (`debug_gpu_census`, modern against classic). The knobs `kSpecF0Scale`, `kEnvStrength` and `kReflectionMipMax` are in `PgDiff.hlsl`.

## Cost

A/B in one spot (2026-11-13, HMD, gameplay, last ~30 s of each run; per frame, both eye passes):

| | Pixels | Draws | GPU, original (1 tap) | GPU, ours (9 taps) |
|---|---|---|---|---|
| PgFastFP | 2.02 Mpix | 380 | 0.50–0.57 ms | 0.54–0.61 ms |
| PgScrubLightFP | 0.5 Mpix | 332 | 0.065 ms | 0.06 ms |

- The difference is about +0.05 ms, within the window-to-window spread.
- Frame GPU was ~10.4 ms in both runs.
- The extra taps hardly cost anything: the shader is dominated by its overdraw, and neighbouring point-sampled taps hit the cache. So there's no need for fewer taps or hardware PCF on cost grounds.

## OPEN

- **Live (2026-11-13), the two sun-only vegetation shaders:**
  - They substituted at load: vegetation 13 creations, distant 5. No errors.
  - Vegetation shadows look better, and nothing came out unlit. So the `float4`-typed constant arrays (the originals' CTAB says `void`) don't matter to the game.
- **Live (2026-11-13), all 14 vegetation variants:** substituted at load with no errors, 90 Hz held, nothing visibly wrong. The 12 lit variants draw only near the game's point and spot lights. Those are hard to pin down in play, so the lit paths were not specifically observed: accepted as working, revisit if vegetation lighting looks wrong near fires or lamps. `tools/shader_equiv.py` has since verified the lit variants' math against the originals.
- **Live (2026-11-13):** PgBillboardTreeFP and the 7 PgDecal2FP variants. All substituted, no visible issues. The decals draw rarely, at certain places: indoors at the start was one.
- **Math, all 24 replacements (2026-11-13):** `shader_equiv.py` finds 0 differing, max error ~1e-16. That includes the 12 lit vegetation and 6 lit decal variants that couldn't be observed in game.
- **All 27 single-tap receivers are reimplemented (2026-11-14):** both checks pass on every one. `shader_equiv.py` mocks `dsx`/`dsy` as an affine function, and enlarges the `Waves` footprint scales so the wave branches run.
- **Live (2026-11-14):** the five water shaders (PgUnderwaterFP, PgWaterFPDWE, PgWaterFP, PgWaterFPbl, PgWaterFP_LI). All 27 substituted, no visual issues.
- **Live (2026-11-15):** the 21 PgDiff variants (with the cascade blend band). All 48 substituted, no visible issues.
- OPEN, live check: the 35 terrain shaders and the 259 remaining PgDiff shaders (2026-11-15).
